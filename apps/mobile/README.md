# App Volt (conductor)

Aplicación móvil React Native/Expo, cliente de la API `/v1`. Español como idioma principal e inglés disponible (ADR 0005). Registro de tarjeta con tokenización de Wompi y 3D Secure (ADR 0002), mapa con estado en vivo, precio desagregado visible antes de cargar, QR, inicio y parada, progreso en vivo, historial y recibos, deudas y pago, notificaciones push. Se construye en la iteración 7. La app nunca contiene lógica de tarifas, secretos ni acceso a la base de datos.
