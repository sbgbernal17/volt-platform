# Back-office del operador

Aplicación web (React + Vite) para operaciones: mapa y lista con estado en vivo, cargadores, sesiones, comandos remotos, tarifas y simulador de precio, parámetros por nivel, pagos y deudas, alarmas, auditoría y bitácora por cargador. Se construye en la iteración 6 (`docs/plan-de-trabajo.md`, sección 5). Autenticación con Identity Platform y MFA obligatorio para roles administrativos (SEG S6).
